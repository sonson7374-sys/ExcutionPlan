# 실행계획서 관리 시스템

엑셀 실행계획서를 웹 화면으로 옮긴 사내 도구입니다.
이 저장소는 **설치본을 받는 자리**입니다. 소스는 여기 없습니다.

## 내려받기

**[→ 최신 설치본 받기 (Releases)](../../releases/latest)**

| 파일 | 크기 | 어떤 판인가 |
|---|---|---|
| `ExecutionPlan-Setup-1.0.0.exe` | 92 MB | 가벼운 판. 기본 브라우저로 열립니다 |
| `ExecutionPlan-Desktop-Setup-1.0.0.exe` | 205 MB | 데스크톱 앱 판. 자체 창으로 뜹니다 |

둘 중 **하나만** 받으면 됩니다. 잘 모르겠으면 위쪽(92 MB)을 받으세요.

## 설치와 첫 실행

1. 받은 파일을 더블클릭하면 설치되고 바탕화면에 바로가기가 생깁니다.
2. **처음 한 번** DB 비밀번호를 묻는 창이 뜹니다. 담당자에게 받아 넣으세요.
3. 한 번 넣으면 이 PC 에 저장되어 다음부터는 묻지 않습니다.

비밀번호를 잘못 넣었거나 나중에 바뀌면, 프로그램의 **파일 → DB 비밀번호 변경…** 에서 다시 넣을 수 있습니다.

## 이 설치본에는 비밀번호가 들어 있지 않습니다

접속 주소와 계정만 담겨 있고 비밀번호는 없습니다. 그래서 첫 실행에서 묻습니다.

## 무엇이 담겼나

- 실행계획서 최대 **36개월(3년)**
- 인력 명부는 수행부문(개발·운영) 소속이거나, 수행부문이 데려간 사람만 셉니다
- 투입률 화면의 투입·미투입 인원은 **그 달** 기준입니다 (화면에 기준월이 적힙니다)
- 엑셀 서식 2종 동봉 (V1.4 · V1.9-36M)
